# Stengel Lab Bioinformatics

An educational bioinformatics resource for the Stengel Lab at Albert Einstein College of Medicine.

The current milestone adds a detailed [CUT&RUN educational tutorial draft](docs/assays/cut-and-run/index.md), linked software references, installation candidates, and a scientific decision log. Its commands reconstruct observed lab methods; analysis execution and scientific acceptance are pending. Production pipelines are a future milestone.

Start with [getting started](docs/getting-started/index.md), the [software reference](docs/software/index.md), and the [tutorial roadmap](docs/assays/index.md). See [CONTRIBUTING.md](CONTRIBUTING.md) for review expectations.

## Repository layout

## Read or preview the documentation

All source pages are Markdown and can be read directly on GitHub. A local preview uses MkDocs with the Material theme. Follow the [preview instructions](docs/getting-started/preview.md). No deployment is configured.

## Publication boundary

This repository is public. Private inventories, source scripts with unclear publication rights, unpublished findings, sample metadata, credentials, and institutional configuration must remain outside tracked content. Local discovery records are ignored by Git and are not part of the website.

The repository currently has no license file. Maintainers must select appropriate terms before representing its contents as licensed for reuse.
