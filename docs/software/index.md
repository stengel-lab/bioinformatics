## Use the library

Start with the [installation overview](../installation/index.md) for Linux, macOS, Windows/WSL2 and HPC. For several tools together, use the [CUT&RUN environment candidates](../assays/cut-and-run/installation.md#candidate-environments).

Examples require configured inputs and have not been executed as a complete analysis. Historical versions are listed only when evidenced; unknown versions are labeled on individual pages. SEACR and CUT-RUNTools remain [method alternatives](../assays/cut-and-run/methods-comparison.md), rather than requirements of the selected lesson.

To add a tool, use the [tool template](../contributing/templates/tool.md).
