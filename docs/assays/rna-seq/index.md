# RNA-seq tutorial outline

Status: outline. No commands or example dataset are released here yet.

## Proposed scientific question

How does measured RNA abundance differ between biological conditions?

## Decisions the tutorial must explain

Library layout and strandedness, adapters, splice-aware alignment, annotation, feature counts, normalization, and experimental design.

## Evidence needed before publication

Choose an approved public or synthetic dataset, review the processing choices against primary methods, specify the environment and reference data, and document expected inputs, outputs, and quality checks. Resolve alternative implementations before presenting a recommended command sequence.

Develop the lesson with the [tutorial template](../../contributing/templates/tutorial.md). Record execution evidence and scientific review separately.
