# Contributing documentation

Start with the repository's contribution guide on GitHub. The writing templates below define the information needed for a reviewable tool entry or tutorial.

- [Tool template](templates/tool.md)
- [Step-by-step tutorial template](templates/tutorial.md)
- [Review record template](templates/review-record.md)
- [Provenance conventions](provenance.md)
- [Publication review](publication.md)

Keep the website independent of private evidence storage. A public page may cite an approved opaque source identifier; the private evidence map supplies the original path, file hash, line range, and review notes to authorized reviewers.
