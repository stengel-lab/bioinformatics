# Stengel Lab Bioinformatics

Learn how bioinformatics processing choices connect experimental measurements to scientific interpretation.

This resource is being built in Markdown. Start with the [CUT&RUN walkthrough](assays/cut-and-run/index.md), which reconstructs observed lab processing from paired reads to interpretation. It includes linked software pages and explicit scientific review gates; analysis execution remains pending. Other assay pages remain outlines.

- [Getting started](getting-started/index.md): choose a learning path.
- [Software reference](software/index.md): tool roles, usage and environment considerations.
- [Installation](installation/index.md): plan an appropriate computing environment.
- [Concepts](concepts/index.md): file formats, coordinates, and evidence.
- [Assay tutorials](assays/index.md): CUT&RUN draft and planned learning objectives.
- [Contributing](contributing/index.md): write and review a new page.

Tutorial execution and scientific validity are separate review questions. An outline or successful website build does not establish either.
