## What is available

The software library covers read QC, trimming, alignment, peaks, coverage, statistics and visualization. The CUT&RUN guide provides a practical sequence with commands, expected outputs and inspection checks. Detailed explanations, source reconstruction and scientific review remain linked as reference material.

**Status:** CUT&RUN is an educational draft, not an execution-validated protocol. Installation candidates and biological processing examples have not been run end to end. No sequencing data or automated production pipeline is distributed. Other assays are outlines. See the [validation record](assays/cut-and-run/validation.md) for the checks actually performed.
