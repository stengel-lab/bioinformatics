# hg38 reference files

Download reference resources from their original providers and generate any derived files locally. **We do not upload genome files or prebuilt indexes to this repository.**

The baseline CUT&RUN walkthrough requires an **hg38 Bowtie2 index**. A human FASTA is used to build that index. Other resources below are relevant to later analyses, but are **not required by the three baseline scripts**.

## 1. Download hg38 FASTA

UCSC distributes [hg38 genome sequences](https://hgdownload.gi.ucsc.edu/goldenPath/hg38/bigZips/). The example below uses the named `hg38.fa.gz` from that directory (the original release), so the download is explicit and repeatable.

```bash
mkdir -p references/hg38
cd references/hg38

curl -fL -O https://hgdownload.gi.ucsc.edu/goldenPath/hg38/bigZips/hg38.fa.gz
gzip -dk hg38.fa.gz
```

**Output:** `hg38.fa` (and the retained `hg38.fa.gz`). Allow several GB of disk space for the uncompressed FASTA and the index. UCSC also maintains a [latest sequence set](https://hgdownload.gi.ucsc.edu/goldenPath/hg38/bigZips/latest/); do not mix those files with the original-release set without checking sequence content and contig names.

## 2. Build a Bowtie2 index

With [Bowtie2](https://bowtie-bio.sourceforge.net/bowtie2/manual.shtml) installed:

```bash
mkdir -p bowtie2
bowtie2-build hg38.fa bowtie2/bowtie_hg38
bowtie2-inspect -s bowtie2/bowtie_hg38
```

**Output:** the Bowtie2 index files, all sharing the prefix `bowtie2/bowtie_hg38`. In the [CUT&RUN walkthrough](../../pipelines/cut-and-run/walkthrough.md#3-bowtie2-align-to-hg38), set `GENOME_INDEX` to the **absolute path to that prefix**, not to an individual `.bt2` file.

**Important:** These commands demonstrate a reproducible index build from UCSC hg38. The exact FASTA and index previously used in the lab have **not** been confirmed to match this download. Have the bioinformatics lead approve the reference choice before treating it as a lab-standard reference.

## 3. Other useful hg38 resources

| Resource | Where to obtain it / how to make it | When needed |
| --- | --- | --- |
| Chromosome sizes | [UCSC `hg38.chrom.sizes`](https://hgdownload.gi.ucsc.edu/goldenPath/hg38/bigZips/hg38.chrom.sizes), or `samtools faidx hg38.fa` and extract the first two columns of `hg38.fa.fai` | Some downstream track and interval tools |
| Gene annotation (GTF/GFF) | Select and document a matching release from [GENCODE human annotations](https://www.gencodegenes.org/human/) | Annotation and gene-focused analyses |
| Genomic blacklist | Obtain an hg38-specific, documented [ENCODE blacklist](https://github.com/Boyle-Lab/Blacklist/) | Optional artifact filtering; not used in baseline scripts |
| Spike-in genome | Download the species/assembly specified by the experimental protocol and build an appropriately identified combined reference if required | A future spike-in-normalization branch, not baseline |

If using a downloaded chromosome-sizes file alongside a locally built FASTA/index, confirm that the sequence names and lengths agree. Do not mix genome assemblies or annotation versions without checking compatibility.

## Reproducibility

Record the download URL and date, assembly/release, included contigs, file checksum, Bowtie2 version, and index-building command. For example:

```bash
sha256sum hg38.fa.gz
bowtie2-build --version
```

Keep large reference files in local, institutional, or HPC storage, not in Git. This page stores **instructions and links only**.
