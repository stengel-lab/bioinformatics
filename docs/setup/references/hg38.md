## Source and reproducibility

Useful authoritative download entry points:

- [UCSC hg38 sequence resources](https://hgdownload.soe.ucsc.edu/goldenPath/hg38/bigZips/)
- [Bowtie2 manual — index construction and alignment](https://bowtie-bio.sourceforge.net/bowtie2/manual.shtml)

Before recommending a lab-standard download or distributing a prebuilt index, verify the **exact source FASTA**, genome assembly and included contigs, sequence naming conventions, Bowtie2 version, index-construction command, and checksums with the lab bioinformatics lead.

We should then provide a small versioned manifest with those details and a stable download location. Large genome FASTAs and indices should **not** be committed as ordinary Git files. We can host approved bundles in suitable storage or provide verified download/build commands.
