# macOS

Use the [documentation preview instructions](../getting-started/preview.md) for a local website. Record the macOS version and whether the computer uses Apple Silicon or Intel.

For analysis environments, verify that the selected package release supports the machine architecture. Distinguish a native binary from an emulated binary and document any compiler or system-library requirements. Shell scripts can depend on GNU command options that differ from the utilities supplied with macOS.

GPU-specific Linux workflows require a separate supported execution environment. Per-tool macOS analysis installation, performance, and scientific output equivalence remain to be reviewed.
