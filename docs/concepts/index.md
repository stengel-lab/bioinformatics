# Concepts and background

The tutorial curriculum should explain the experimental measurement before the software procedure.

| Topic | Learning objective |
|---|---|
| Experimental design | Identify biological replicates, controls, batches, and confounding |
| Read processing | Explain how adapters, quality, mapping, and filtering change retained evidence |
| [Files and coordinates](file-formats.md) | Identify units, sorting requirements, coordinate systems, and genome builds |
| Normalization | State the quantity being scaled and the assumptions behind its denominator |
| Statistical inference | Separate effect size, uncertainty, multiplicity, and biological interpretation |
| [Reproducibility](reproducibility.md) | Connect a result to inputs, code, environments, and review records |

These are curriculum topics. Each complete tutorial must supply assay-specific rationale and primary references.
